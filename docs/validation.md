### 向日葵远端粘贴验收方法

1. 确认 Windows 上运行适配后的程序，记录当前复制次数。远端 Mac 打开“文本编辑”的空白文档。
2. 向日葵在前台时，使用 Windows 微信输入法 Alt+Q 开始语音，说“远端第一轮，苹果”，再结束，等 2 秒。
3. 在远端文档选择 Mac 菜单“编辑 → 粘贴”。如果输入法已经自动送字，另起一行后再粘贴，区分自动送字与实际粘贴。
4. 再识别“远端第二轮，香蕉”，结束后等 2 秒，在新的一行用同一菜单粘贴。确认是第二轮新内容，未残留第一轮。
5. 对照本机成功复制次数、Windows 剪贴板与最终转写的一致性，以及远端实际粘贴内容。仅看到剪贴板所有者为 AweSun 不能判定远端通过。

先使用菜单粘贴验证内容通路，再验证用户平时的粘贴快捷键。若菜单成功而快捷键失败，单独检查快捷键映射；若本机剪贴板正确但远端菜单仍粘贴旧内容，优先检查向日葵同步。
