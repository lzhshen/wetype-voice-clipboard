微信语音复制 · WeType Voice Clipboard

适用环境
Windows 10/11 x64，.NET Framework 4.8。
适配微信输入法 Windows 2.1.4.6 和 3.0.0.34 的已验证程序文件。
工具是非官方兼容工具；不包含或分发微信输入法。

使用方法
1. 启动微信输入法。
2. 双击 WeTypeVoiceCapture.exe，程序会在系统托盘运行，没有主窗口。
3. 使用你原来的语音快捷键（例如 Alt+Q）开始和结束语音。
4. 等语音处理完成、托盘显示“已复制”（通常约 1～2 秒），再在需要的位置粘贴。
   新语音会替换剪贴板的原内容；处理完成前粘贴，仍会得到原剪贴板内容。

正常完成语音后，光标在输入框内或外都应复制。输入框内自动出现文字是输入法自身的送字行为；
本工具是否复制成功，可查看托盘状态或下方状态文件中的复制次数。

鼠标悬停托盘图标可以查看工具版本号和当前状态，右键菜单顶部也会显示工具版本号。
右键托盘图标可以暂停、恢复、配置向日葵自动粘贴、开机启动或退出。两个开关首次运行均默认关闭。
已有旧版本在运行时，先从托盘退出旧版本，再启动新版本。

向日葵自动粘贴（v0.3.0 起）
右键托盘勾选“向日葵自动粘贴”，从下一轮语音生效，重启后保留设置。
先在远控窗口内点击输入框，再开始语音；完成后保持窗口前台，等待自动填入。
复制成功后额外等待约 0.75 秒；等待期间新的键鼠操作也会取消自动粘贴。
每轮最多发送一次 Ctrl+V，不发送回车。切换窗口后再切回也取消本轮自动粘贴。
暂停、关闭开关、输入法重连、开始新一轮都会取消待粘贴；剪贴板复制功能保留。
本机应用和向日葵主界面不自动粘贴。只支持已识别的向日葵 Flutter 远控窗口结构。
“已触发向日葵粘贴”表示按键已发出，不代表远端确认成功；跨设备同步和键位映射仍依赖向日葵。
如果输入法本身已经自动送字，请关闭该开关，避免重复输入。

开机启动配置（v0.2.0 起）
先把程序放到长期保留的目录，运行后右键托盘图标，勾选“开机启动”。
下次当前用户登录 Windows 时，工具会自动在后台托盘运行，无需管理员权限。
微信输入法尚未启动时，工具会自动等待并连接。
再次点击取消勾选，即可关闭；“退出”只结束本次运行，不会取消开机启动。
移动程序或升级后，先退出旧实例，再运行新位置的程序，已有启动设置会自动更新路径。
删除程序前，请先取消勾选。如果在 Windows“启动应用”或任务管理器中禁用过本工具，也需在那里恢复启用。
启动设置保存位置：
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
其中 WeTypeVoiceCapture 的值为带引号的 EXE 完整路径。

远程使用
程序放在录音和运行微信输入法的 Windows 电脑上。
向日葵等远程软件负责现有的跨设备粘贴通路，远程 Mac 不需要运行这个程序。

隐私与行为
只读访问微信输入法已经产生的最终文字，不录音、不联网，不保存识别文字历史。
不操作语音快捷键、不切换焦点；仅在开启上述开关且满足条件时触发向日葵粘贴。
取消由微信输入法处理；本工具不改变快捷键含义。
当前运行状态与复制次数保存位置：
%LOCALAPPDATA%\WeTypeVoiceCapture\status.txt

升级与兼容性
如果微信输入法更新或文件校验不符，程序停止读取并在托盘状态中提示需要适配。
此版本为免安装版本，目前没有代码签名。
