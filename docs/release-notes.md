# 微信语音复制 v0.2.0

新增可配置的开机启动功能。

- 右键托盘图标，勾选“开机启动”，即可在当前用户登录 Windows 时自动后台运行；再次点击可关闭。
- 首次运行默认关闭，设置会保留，无需管理员权限。
- 移动或升级程序后，先退出旧实例，再运行新位置的程序，已启用的启动项会自动更新路径。
- 启动设置读取或修改失败时给出提示，语音复制仍可继续运行。
- 自动验证覆盖默认关闭、启用与取消、中文和空格路径、路径更新，以及保留其他应用启动项。

选择“退出”不会取消开机启动；删除程序前请先取消勾选。如果曾在 Windows“启动应用”或任务管理器中禁用过本工具，也需在那里恢复启用。

在后台读取微信输入法已经完成的语音识别结果，自动复制到 Windows 剪贴板。
使用者继续使用微信输入法原有快捷键，在需要时自行粘贴；工具提供托盘暂停、恢复和退出。

## 下载

- `WeTypeVoiceCapture-v0.2.0-win-x64.exe`：直接运行的单文件程序。
- `wetype-voice-clipboard-v0.2.0-win-x64.zip`：程序、说明和许可证的便携包。
- `SHA256SUMS.txt`：下载文件校验值。

已有旧版本在运行时，先从托盘退出旧版本，再启动新版本。

## 验证情况

已通过本地构建、发行包校验、真实微信输入法只读连接，以及隔离注册表中的开机启动配置检查。
实际重新登录 Windows 后的自动启动尚未完成人工验证。

## 兼容范围

- Windows 10/11 x64，.NET Framework 4.8。
- 微信输入法 Windows 2.1.4.6，且目标程序文件通过内置校验。
- 已在 Windows 通过向日葵控制 Mac 的语音复制与远程粘贴场景实测。

这是非官方兼容工具，不是 macOS 原生程序；Mac 可作为远程粘贴目标。
微信输入法更新后可能需要重新适配。当前程序未进行代码签名。
工具自身不联网、不录音、不保存识别文字历史，不更改语音快捷键或输入焦点。
