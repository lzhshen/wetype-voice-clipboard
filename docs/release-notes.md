# 微信语音复制 v0.2.1

修复完成新一轮语音后，粘贴仍得到上一轮内容的问题。

- 旧版要求轮询必须观察到短暂的“结束处理中”状态；错过该状态时，即使语音已完成，也会跳过新结果，剪贴板保留上一轮文字。
- 新版根据已经观察到的语音轮次、完成标记、稳定的最终文字及取消状态判断是否复制，避免依赖短暂的中间状态。
- 保留每轮只复制一次、取消不复制、启动及恢复时跳过旧结果，以及剪贴板占用时重试的行为。
- 新增直接回放正式轮次处理逻辑的回归检查，并纳入 GitHub Actions。

选择“退出”不会取消开机启动；删除程序前请先取消勾选。如果曾在 Windows“启动应用”或任务管理器中禁用过本工具，也需在那里恢复启用。

在后台读取微信输入法已经完成的语音识别结果，自动复制到 Windows 剪贴板。
使用者继续使用微信输入法原有快捷键，在需要时自行粘贴；工具提供托盘暂停、恢复和退出。

## 下载

- `WeTypeVoiceCapture-v0.2.1-win-x64.exe`：直接运行的单文件程序。
- `wetype-voice-clipboard-v0.2.1-win-x64.zip`：程序、说明和许可证的便携包。
- `SHA256SUMS.txt`：下载文件校验值。

已有旧版本在运行时，先从托盘退出旧版本，再启动新版本。

## 验证情况

已通过本地构建、语音轮次回放回归检查、发行包校验、真实微信输入法只读连接，以及隔离注册表中的开机启动配置检查。
本次以确定性状态回放复现并验证修复，未重新进行真人语音或向日葵端到端粘贴测试；实际重新登录 Windows 后的自动启动也尚未完成人工验证。

## 兼容范围

- Windows 10/11 x64，.NET Framework 4.8。
- 微信输入法 Windows 2.1.4.6，且目标程序文件通过内置校验。
- 已在 Windows 通过向日葵控制 Mac 的语音复制与远程粘贴场景实测。

这是非官方兼容工具，不是 macOS 原生程序；Mac 可作为远程粘贴目标。
微信输入法更新后可能需要重新适配。当前程序未进行代码签名。
工具自身不联网、不录音、不保存识别文字历史，不更改语音快捷键或输入焦点。
