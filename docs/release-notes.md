# 微信语音复制 v0.2.4

调整语音结果写入 Windows 剪贴板的方式，消除 OLE 分阶段发布时，首次变化通知到达但剪贴板尚不可读的时序窗口。用户在向日葵场景确认处理完成后可粘贴最新内容，完成本轮验收。

- 完整 Unicode 文本在一次事务内写入，发布一次剪贴板变化通知。
- 保留原有的轮次判断、取消、暂停/恢复、版本校验、占用重试、托盘版本号和开机启动功能。
- 新增真实 Windows 剪贴板通知、Unicode 内容、占用重试及内容持久性检查，由专用 CI 运行器执行；本地运行需明确允许临时改写剪贴板。

正常结束语音后，光标在输入框内或外都应更新 Windows 剪贴板。输入法自身的直接送字、剪贴板输出和本工具的复制是不同步骤；远程软件负责之后的跨设备粘贴。

请等语音处理完成、托盘显示“已复制”（通常约 1～2 秒）后再粘贴。处理完成前粘贴，仍会得到原剪贴板内容。

## 使用

- `WeTypeVoiceCapture-v0.2.4-win-x64.exe`：直接运行的单文件程序。
- `wetype-voice-clipboard-v0.2.4-win-x64.zip`：程序、说明和许可证。
- `SHA256SUMS.txt`：本次构建的文件校验值。

先退出旧实例，再启动新版。已有开机启动设置会更新到新版路径。首次使用不会自动启用开机启动。

## 验证情况

原有 15 组轮次与快照检查、新增 3 组剪贴板集成检查，以及构建、发行包、真实输入法只读连接、开机启动配置和单实例检查通过。新旧实现各 30 次发布的对比中，首个通知读取遇到占用的次数由 30 次降至 0 次。

本轮检查结果、用户远端验收反馈与历史验收范围见 [验证记录](https://github.com/lzhshen/wetype-voice-clipboard/blob/v0.2.4/docs/validation.md)。

## 兼容范围

Windows 10/11 x64，.NET Framework 4.8；微信输入法 2.1.4.6 / 3.0.0.34，且目标程序通过内置校验。
这是非官方兼容工具，不是 macOS 原生程序；Mac 可作为远程粘贴目标。程序目前未进行代码签名。
工具自身不联网、不录音、不保存转录正文，不更改语音快捷键或输入焦点。
