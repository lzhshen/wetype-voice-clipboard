# 微信语音复制 v0.3.0

新增托盘开关“向日葵自动粘贴”，默认关闭，设置在重启后保留。开启后，从下一轮语音起，在已识别的向日葵远控窗口保持前台时，复制成功后额外等待约 0.75 秒，最多触发一次 Ctrl+V。

- 语音期间或等待期间切换窗口，本轮自动粘贴取消；切回原窗口也不恢复。
- 等待期间新的键鼠操作、暂停、关闭开关、输入法重连或下一轮语音，都会取消待执行的粘贴。
- 本机应用、向日葵主界面和无法识别的窗口保持原有复制行为，不额外粘贴。每轮不发送回车，不重试已发出的按键。
- 开关和自动粘贴触发次数可在托盘/本地状态文件中确认；不记录语音正文或窗口标题。

自动粘贴仍依赖向日葵的剪贴板同步及 Ctrl/Command 映射；“已触发”表示按键已发出，不代表远端确认收到文字。若输入法本身已能向远端自动送字，请关闭本开关以免重复。

新增 13 组自动粘贴行为检查，覆盖窗口切换、连续轮次、取消、复制重试、开关持久性和按键发送边界。原有回归检查及真实远端验收状态见 [验证记录](docs/validation.md)。

## 使用

先退出旧实例，再启动新版；已有开机启动设置会更新到新版路径。首次运行默认关闭两个开关。在远控输入框中开始语音前，按需勾选“向日葵自动粘贴”；语音结束后保持窗口前台，等待文字填入。

支持 Windows 10/11 x64、.NET Framework 4.8、经校验的微信输入法 2.1.4.6 / 3.0.0.34，以及已识别的向日葵 Flutter 远控窗口结构。

继续保留 v0.2.4 的一次性剪贴板写入、占用重试，以及原有取消、暂停恢复、版本校验和开机启动功能。关闭自动粘贴时，仍可等“已复制”后手动粘贴。

下载包包含单文件 EXE、便携 ZIP 和 SHA256SUMS.txt。程序未签名，不联网、不录音、不保存转录正文，不更改语音快捷键或输入焦点。
