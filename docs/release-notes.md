# 微信语音复制 v0.2.3

在 v0.2.2 基础上增加托盘版本号展示，方便确认当前运行的是哪个版本。保留最新转录粘贴修复，以及微信输入法 Windows 2.1.4.6 / 3.0.0.34 的兼容支持。

- 鼠标悬停托盘图标时显示“微信语音复制 v0.2.3”和当前运行状态，状态更新后仍保留工具版本号。
- 右键菜单顶部固定显示工具名称和版本号。
- 版本号读取程序内的构建信息，与 `VERSION` 自动保持一致。

正常结束语音后，光标在输入框内或外都应更新 Windows 剪贴板。输入法自身的直接送字、剪贴板输出和本工具的复制是不同步骤；远程软件负责之后的跨设备粘贴。

## 使用

- `WeTypeVoiceCapture-v0.2.3-win-x64.exe`：直接运行的单文件程序。
- `wetype-voice-clipboard-v0.2.3-win-x64.zip`：程序、说明和许可证。
- `SHA256SUMS.txt`：本次构建的文件校验值。

先退出旧实例，再启动新版。已有开机启动设置会更新到新版路径。首次使用不会自动启用开机启动。

## 验证情况

本地构建、15 组回归检查、发行包检查、真实输入法只读连接及隔离注册表中的启动配置检查通过，EXE 产品版本确认为 `0.2.3`。

本轮检查结果与历史验收范围见 [验证记录](https://github.com/lzhshen/wetype-voice-clipboard/blob/v0.2.3/docs/validation.md)。v0.2.2 的本地语音和向日葵远端 Mac 粘贴验收保留在对应章节，不计作本轮真人验收。

## 兼容范围

Windows 10/11 x64，.NET Framework 4.8；微信输入法 2.1.4.6 / 3.0.0.34，且目标程序通过内置校验。
这是非官方兼容工具，不是 macOS 原生程序；Mac 可作为远程粘贴目标。程序目前未进行代码签名。
工具自身不联网、不录音、不保存转录正文，不更改语音快捷键或输入焦点。
